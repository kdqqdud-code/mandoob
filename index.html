🤖 My AI Agent

وكيلك العام لتنفيذ مهام البرمجة وإدارة المشروع من الهاتف عبر GitHub Actions.

كيف تستخدمه؟

1
افتح مستودع my-ai-agent من هاتفك.
2
أنشئ Issue جديدة واكتب المهمة التي تريدها.
3
اكتب المهمة في تعليق داخل الـIssue. الوكيل يقرأ التعليق ويبدأ التنفيذ.
4
سيعدل الملفات ويختبرها ويحفظ التغييرات ويرد عليك بتقرير.

مثال

أنشئ صفحة تسجيل دخول بسيطة للمشروع، استخدم التصميم الموجود، ثم شغّل الاختبارات وأصلح أي خطأ يظهر.

⚙️ الإعداد الوحيد المطلوب

ضع مفتاح Gemini في GitHub Secret باسم:

GEMINI_API_KEY
لا تضع المفتاح داخل ملفات المشروع أو داخل هذه الصفحة.
